API Reference

Inputs, outputs, methods, and configuration for the standalone PdfViewerComponent.

PdfViewerComponent

Standalone component that renders a PDF document. Import it directly — no modules required.

Inputs

Input Type Default Description
src string | Uint8Array | PDFSource — PDF source — see supported source types (URL, bytes, base64, Blob, or a document parameters object)
page number 1 Current page number
renderText boolean true Enable text layer
renderTextMode RenderTextMode ENABLED Text layer mode
originalSize boolean false Render at original page size instead of fitting
stickToPage boolean false Keep scale changes anchored to current page
zoom number 1 Zoom multiplier
zoomScale 'page-width' | 'page-height' | 'page-fit' 'page-width' Scale mode
rotation number 0 Page rotation (0, 90, 180, 270)
autoresize boolean true Re-render on container/window resize
fitToPage boolean true Fit content to container
showBorders boolean false Show page borders
cMapsUrl string | null null CMap URL for CJK text; null falls back to the CDN default
externalLinkTarget 'blank' | 'self' | 'parent' | 'top' | 'none' 'blank' Target for external URLs
enableHandTool boolean config, else false Enable pan/drag hand tool; unbound falls back to providePdfViewerConfig
annotationMode AnnotationDisplayMode 'enabled' Annotation display mode: 'none' | 'enabled' | 'forms' | 'storage'
locale string 'en' Locale for PDF.js localization
loadingTemplate TemplateRef | null null Custom loading overlay while the document is fetched
passwordProvider (reason: number) => Promise<string | null> — Async password prompt for encrypted documents; reason is a pdf.js PasswordResponses code (1 = NEED_PASSWORD, 2 = INCORRECT_PASSWORD); return null to cancel

providePdfViewerConfig

Provider to configure the viewer globally: {{ '{' }} cdnBaseUrl?, workerSrc?, cMapsUrl?, standardFontDataUrl?, wasmUrl?, iccUrl?, imageResourcesPath?, enableHandTool?, maxCanvasPixels? {{ '}' }}. pdf.js loads from a CDN by default — worker, cMaps, standard fonts, WebAssembly image decoders and the CMYK ICC profile are all resolved automatically. Override individual URLs to self-host, or cdnBaseUrl to point at a different CDN entirely.

Example
providePdfViewerConfig({
  cdnBaseUrl: 'https://unpkg.com/pdfjs-dist@6.3.289/',
  enableHandTool: true,
})
info
maxCanvasPixels — usually leave it unset pdf.js already picks a platform-aware cap: 2**25 (33,554,432px) on desktop, and 5,242,880px on iOS/Android where canvas memory is scarce. Past the cap it renders at a lower effective pixel ratio rather than allocating. Overriding raises the mobile cap too — and one page canvas at page-width zoom on a HiDPI display is already about 25 MB, with up to 10 kept buffered. Raise it only for a measured sharpness problem at high zoom.

Errors

Failures reach you through the error output as a PdfViewerError carrying a stable code plus the original cause.

Code Raised when
INVALID_SOURCE src is empty or not a recognised source shape.
LOAD_FAILED Network, CORS, or a malformed/corrupt PDF.
PASSWORD_REQUIRED Encrypted PDF and no passwordProvider bound.
PASSWORD_CANCELLED The provider returned null or threw.
INVALID_STATE A document method ran before a document finished loading.
RENDER_FAILED PDF.js failed while rasterising or scaling a page.
warning
Document methods throw before load getOutline, getMetadata, getThumbnail, download and print reject with INVALID_STATE if no document is loaded. getPageCount() returns 0 instead of throwing, so it is the safe guard.
