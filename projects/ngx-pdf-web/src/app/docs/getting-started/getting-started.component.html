Getting Started

Install the library and render a PDF with the standalone ngx-pdf-viewer component — pdf.js loads automatically from a CDN at runtime.

1 Installation

No peer install, no stylesheet to wire up, no worker file to copy.

terminal Install 
pnpm add @gavsby/ngx-pdf-viewer
# or
npm install @gavsby/ngx-pdf-viewer

The library is headless and does not ship a custom visual theme — use Angular Material system tokens (--mat-sys-*) and Angular Aria for your chrome.

info
Runtime CDN pdf.js loads from a CDN by default, so it needs internet access. To go offline or satisfy a strict Content-Security-Policy, serve a copy of the pdfjs-dist package yourself and point cdnBaseUrl at it — every other URL is derived from that one. Individual overrides (workerSrc, cMapsUrl, standardFontDataUrl, wasmUrl, iccUrl) are there for mixed setups.

2 Render a document

Give the host a definite height (flex child or height: 100%). The viewer is position: absolute; inset: 0 inside that host.

code document-viewer.component.ts 
import {{ '{' }} PdfViewerComponent {{ '}' }} from '@gavsby/ngx-pdf-viewer';

@Component({{ '{' }}
  selector: 'ngx-document-viewer',
  standalone: true,
  imports: [PdfViewerComponent],
  template: `
    <ngx-pdf-viewer
      [src]="pdfSrc"
      [page]="page"
      [zoom]="zoom"
      (afterLoadComplete)="onLoaded($event)"
      (pageChange)="page = $event"
      (error)="onError($event)"
    />
  `,
  styles: [`:host {{ '{' }} display: block; height: 100%; {{ '}' }}`],
{{ '}' }})
export class DocumentViewerComponent {{ '{' }}
  pdfSrc = 'https://mozilla.github.io/pdf.js/web/compressed.tracemonkey-pldi-09.pdf';
  page = 1;
  zoom = 1;
{{ '}' }}
lightbulb
Sources [src] accepts a URL string, raw bytes, or a pdf.js parameters object — see below for every format.

3 PDF sources

[src] accepts anything pdfjs-dist's getDocument() accepts: string | URL | Uint8Array | ArrayBuffer | PDFDocumentParameters. A plain string is always treated as a URL to fetch — decode base64 and Blob sources to bytes first.

URL

Same-origin or CORS-enabled remote URLs are fetched directly by the worker.

URL string
pdfSrc = 'https://example.com/report.pdf';
// or same-origin
pdfSrc = '/assets/report.pdf';

Uint8Array / ArrayBuffer

Bytes you already have in memory — a fetch() response, IndexedDB, and so on.

Raw bytes
const response = await fetch('/reports/report.pdf');
this.pdfSrc = new Uint8Array(await response.arrayBuffer());

Base64

Decode to bytes before binding — a base64 string passed directly to [src] is read as a URL and will fail to load.

Base64 → Uint8Array
function base64ToBytes(base64: string): Uint8Array {
  const binary = atob(base64);
  return Uint8Array.from(binary, (c) => c.charCodeAt(0));
}

this.pdfSrc = base64ToBytes(base64Pdf);

Blob / File

From a <input type="file"> element or a download — convert to bytes the same way.

File input
onFileSelected(event: Event) {
  const file = (event.target as HTMLInputElement).files?.[0];
  if (!file) return;
  file.arrayBuffer().then((buf) => (this.pdfSrc = new Uint8Array(buf)));
}

PDFDocumentParameters

For authenticated requests, a known password, or any other pdf.js document parameter, pass an object instead of a bare source.

Authenticated request
this.pdfSrc = {
  url: '/reports/report.pdf',
  httpHeaders: { Authorization: `Bearer ${token}` },
  withCredentials: true,
};

4 Search

Call methods on the component instance. Results emit on searchResults as { current, total }.

Search API
@ViewChild(PdfViewerComponent) viewer!: PdfViewerComponent;

search(query: string) {
  this.viewer.search(query);
}

next() { this.viewer.findNext(); }
previous() { this.viewer.findPrevious(); }
clear() { this.viewer.clearSearch(); }

Troubleshooting

Give the host a non-zero height (flex child or height: 100%). Check the browser console for worker or CORS errors.
The PDF URL must allow cross-origin reads. Serve files from your own origin, or enable CORS on the remote host. Passing a Uint8Array avoids CORS entirely.
Bind [passwordProvider]. It receives a pdf.js password reason code and should return the password string, or null to cancel (PASSWORD_CANCELLED).
