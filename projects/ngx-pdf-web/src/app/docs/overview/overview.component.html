ngx-pdf-viewer

A lightweight, type-safe PDF viewer for Angular — built on PDF.js with full control over styling, accessibility, and behavior. No wrappers, no iframes.

rocket_launch Get started play_circle Live demo API reference

Why ngx-pdf-viewer?

bolt

Lightweight & fast

Minimal dependencies, tree-shakable, and lazy-loaded via intersection observer.

shield

Type-safe

Full TypeScript strict mode, typed inputs/outputs, and PDF.js types re-exported.

widgets

Standalone

Built for modern Angular — no NgModules, signal inputs and outputs, OnPush throughout.

palette

Customizable

Headless page rendering — bring your own toolbar and restyle every PDF.js layer.

search

Search & outline

Integrated find controller, thumbnail rendering, and outline extraction APIs.

accessibility

Accessible by design

The viewer renders a real text layer and marks its container aria-busy while loading — the toolbar is yours, so its ARIA is yours too.
